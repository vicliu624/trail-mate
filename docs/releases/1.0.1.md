# Trail Mate 1.0.1 delivery

This patch corrects an integration omission in the first stable release:
Pager SX1262, Pager LR1121 and standard T-Deck/T-Deck Plus firmware did not
include the USB CDC HostLink management path used by the browser tools.
Both the transport/service configuration and the core library exclusion are
corrected. The application loop starts management only when the host opens CDC,
and disconnecting releases the task and queues. The existing storage ownership
and device-author signature rules still apply.

Version **1.0.1** is a patch because it restores the advertised browser-management
behavior without changing its wire protocol or requiring users to migrate data.
The [GitHub release](https://github.com/vicliu624/trail-mate/releases/tag/v1.0.1)
is published as a stable release and supplies the authoritative tag and files.

## Installation

Install the exact board/radio image. Pager SX1262 and LR1121 images are different;
T-Deck/T-Deck Plus use `tdeck`. Select the running application's USB port for
browser management. The ROM download port is used only to install firmware.
Release images retain disabled full DFU and DFU Runtime; BOOT + RESET still
provides ROM downloading.

The existing 1.0.0 images do not acquire this service by reloading a Web page.
Use Device management in a secure-origin browser with Web Serial support after
installing 1.0.1. The device's USB SD-card mode has exclusive storage ownership;
leave that mode before configuration or stored-content management.

## Web changes

Animal Island UI is pinned to 2.2.1 and naive-icons to 1.6.0. Device fields use
the library Input, including its invalid state. Native controls retained for
file/range APIs and dynamic editors share public theme tokens, focus and disabled
styles. Long ribbon titles wrap. Connection status shows progress and failures
retain their serial/handshake stage and original receive diagnostic.

Track maps share an initialization factory that avoids Leaflet 1.9.4's retained
zoom completion callback after a React view is removed. A browser regression
first reproduced the original exception, then passed with the public-option
workaround. Map dragging, pan animation, zoom controls and fitting remain usable.

The homepage explains why privacy matters: device-held keys, pseudonymous
authorship, local records and independent services reduce the personal
information a platform needs to hold. Public keys and intentionally published
locations remain observable; the copy does not promise untraceable networking.

## Validation scope

Serial transport, management correlation and device author proof regression
tests pass locally, including lost connections, lock cleanup, handshake stages
and receive errors. Built browser flows cover configuration edit/review/save and
reconnect/readback using simulated USB with real cryptographic proofs. Language
switching preserves unsaved KML edits, DOM identity and map state in 11 locales.
Shared navigation passes 58 page/locale checks across five widths. Homepage copy
and privacy links pass 44 locale/width combinations. ESP stack hygiene passes.
The three affected PlatformIO environments also completed local builds
successfully. Shared-package disposal, workspace persistence/unsaved edits and
local/shared region preview checks pass after the map lifecycle correction.

Local hardware enumeration currently exposes no connected Pager or T-Deck.
Synthetic USB and firmware builds do not establish physical USB acceptance.
