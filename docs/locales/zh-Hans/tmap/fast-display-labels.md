# TMAP 连续显示标注区

## 目标与兼容性

原标注链为瓦片索引 → 标注记录 → 几何 → POI 行 → 名称行 → 字符串。即使每一步都是常数时间寻址，随机 SD 读和任务调度仍会使显示变慢。新增可选段 43、44 将绘制需要的字段物化在一起；完整 POI、名称、空间和搜索段保留，显示名称截断不影响搜索库。

两段的 schema=1，flags=2（分页、可选），owner=0。旧 reader 可忽略可选段；新 reader 优先使用新段，缺少两段时使用旧标注链。只存在其中一段属于不完整包。现有 mandatory capability 和 normalization_profile=2 不变。

## 二进制布局

段 43 为标准 4096 字节固定行表，页头 64 字节，page type=9，每行 176 字节，每页最多 22 行。row ID 从 1 开始。

| 行内 offset | 长度 | 内容 |
|---|---|---|
| 0 | 16 | 完整 stable POI ID |
| 16 | 4 | 显示锚点纬度，i32 E7 |
| 20 | 4 | 显示锚点经度，i32 E7 |
| 24 | 2 | 标注 kind，u16 |
| 26 | 2 | 标注 priority，u16 |
| 28 | 1 | 短路径点数，0–8 |
| 29 | 1 | 显示名称 UTF-8 字节数，0–79 |
| 30 | 2 | reserved=0 |
| 32 | 80 | UTF-8 名称，NUL 结尾；仅在完整 Unicode scalar 边界截断 |
| 112 | 64 | 最多 8 对纬度/经度，i32 E7，未用部分为 0 |

段 44 为数字键 B+ 树，键为原有 z/Morton(X,Y) 的 u64。叶值 16 字节：first_row u64、count u32、reserved u32=0。每个瓦片的标注连续存放，count=1–200。没有标注的瓦片不建叶记录。

行定位：page=floor((row-1)/22)，slot=(row-1)%22；物理地址=section.offset+page×4096+64+slot×176。整个页通过 CRC 后才消费行。与其他段一样，所有多字节字段为小端。

显示锚点可能不同于完整 POI 的目标坐标。点击、搜索和导航使用 stable ID 查完整 POI；不把显示行当作完整 POI 记录。段 43 不包含完整别名、分类、地址或路网。

## 复杂度与资源

令 T 为有标注的瓦片数，A 为一个瓦片的标注数，B 为索引扇出，s 为第一行在页内的 slot。

- 定位：O(log_B T)，无需扫描 POI 表。
- 绘制数据读取：O(ceil((s+A)/22)) 个连续表页，CPU 为 O(A)。s∈[0,21]，最多比按页对齐多一页。
- 显示区空间：约 176A 字节加页头/页尾空隙；名称为显示副本，完整搜索名称不重复截断。
- reader 继续使用两个 4 KiB 页缓存；游标新增 184 字节并仍受 1 KiB 编译期上限约束，位于 PSRAM。
- 独立 POI 定位使用标注索引，与底图像素是否存在分离；可以安装只有 POI/搜索/标注的 OSM 包，给地形和卫星包提供叠加。

worker 内保留短段 POI More 请求，减少每一阶段的 UI 往返；累计约 100 ms 后发布重试以允许其他地图任务执行。部分标注快照也会完成当前请求。底层一次 SD 操作可能超过预算，因此不是硬实时保证。

## 成品升级与 USB 更新

Center 的 fast-labels-upgrade 在电脑上生成两段并追加到旧包尾部。仅备份原始前 8 KiB 和原文件长度，不复制完整包。新段全部校验后更新包目录、file length、build ID、revision 和 CRC。

fast-labels-install 将电脑准备好的尾部增量安装到匹配的旧包：检查 package/series、原段目录、不可变头字段和 revision 关系；只传新增数据与前 8 KiB。先持久化数据，再发布目录和包头，最后读取新标注校验。失败回滚包头和长度；断电后的日志可由再次执行安装恢复。

USB 更新期间设备不能使用 SD；更新完成后退出 USB 存储并重建介质会话或重启。新数据未在硬件日志中测量前，不能仅凭 PC 生成速度声称设备提速比例。
