# TMAP 搜索结果行政区位置

## 目的与状态

搜索结果需要用行政区路径区分同名地点。距离排序不能代替行政区信息，
也不能把最近的另一个地点作为行政区归属。Center 使用边界多边形包含查询，
生成与 POI 行号对应的行政区引用；设备不加载边界几何。

当前已接通 Center 的数据清单选择、制作前校验、写入、设备读取和列表显示。
Center 英文界面的真实截图与步骤见 Wiki 6.2。尚未把真实全球／中国行政区
数据升级到现有地图包，不能据此宣称行政区层级已经齐全。

## 输入与制作顺序

清单版本为 1，包含 Sources 数组。每项提供：

| 字段 | 含义 |
| --- | --- |
| Path | 清单目录树内的 GeoJSON 相对路径 |
| Level | 显示路径位置 0–5；0 为国家，其余按数据源真实层级填写 |
| CountryCode | 三位大写字母国家标识，如 CHN；不同于包配置中的 CN 示例 |
| CountryName | 显示用国家名称 |
| Source / License | 来源版本、出处和许可记录 |
| Sha256 | 文件 SHA-256，64 位十六进制 |
| NameProperty | 本地名称字段，默认 shapeName |
| EnglishNameProperty | 可选英文名称字段；缺失或空白时使用本地名称 |

输入为 WGS84 经度／纬度顺序的 GeoJSON FeatureCollection，只接收 Polygon
和 MultiPolygon；单文件最多 256 MiB。环必须闭合，几何必须有效。
行政层级在各国含义不同，例如县级数据不能为了填补城市层级而改称城市。

导出选择清单后，先检查文件、哈希与几何，再导入 PBF、生成像素和索引。
边界几何与来源清单保留为同一份快照，最终写入复用该快照；不会对每种底图
反复解析边界。先生成行政区路径，再收集字体字符，使新增文字进入配套字库。
未选择清单时界面明确提示没有行政区信息，当前仍允许制作仅含原始 POI 的包。

## 包内布局

- section 50：固定 16 字节的引用表，行号与 section 20 的 POI 一一对应。
- section 51：分页 UTF-8 字符串池，路径最长 512 字节，重复路径共用字符串。
- section 54：来源、处理方法及统计等 JSON 元数据。

引用表布局如下，整数为小端：

| 偏移 | 长度 | 含义 |
| --- | --- | --- |
| 0 | 8 | section 51 内的路径字符串偏移；零表示没有路径 |
| 8 | 1 | 层级位掩码，bit 0–5 表示对应层级存在 |
| 9 | 1 | bit 0 表示不完整，bit 1 表示归属有歧义 |
| 10 | 3 | 国家标识 ASCII 字节 |
| 13 | 3 | 保留，必须为零 |

每页含 64 字节页头，最多 252 条引用记录。POI 行号为 r（从 1 开始）时：

```text
page = floor((r - 1) / 252)
slot = (r - 1) mod 252
offset = section_offset + page × 4096 + 64 + slot × 16
```

记录定位为 O(1)；字符串也使用直接偏移且不跨页。读取最多涉及引用页和
字符串页，不扫描瓦片或其他缩放等级。引用数必须等于 POI 数；只缺少其中
一个行政区段视为损坏。两个段都不存在的旧包返回明确的未知状态。

## 包含查询、跨日期变更线与质量

电脑端按层级建立 STRtree，先用外包矩形筛选，再用准备过的多边形 Covers
检查点位置。路径按层级顺序合并相邻重复名称。缺少国家、第一或第二层级
标记不完整；同层级多个多边形匹配标记歧义，不按距离或面积随意选择。

跨 ±180° 经线的闭合环展开为连续经度空间；查询经度 λ、λ−360、λ+360，
并去重相同匹配对象。孔洞对齐到外环的经度空间。显式沿极点切开的闭合
平面表示可保留；无法形成闭合平面表示的绕极点环要求先拆分处理。
上述全球几何处理已编译，但尚未用完整真实全球边界集验证。

设边界对象数 A、顶点总数 V、POI 数 N、不同路径数 U：

- 文件哈希与解析随输入字节数线性增长；STRtree 建树约为 O(A log A)。
- 每次查询最多 6 层、每层 3 个经度点。常见外包矩形筛选约为
  O(log A + 候选数)，精确包含的代价还取决于候选边界顶点和几何索引。
- 外包矩形重叠很严重时，不保证对数查询；最坏需检查大量边界及其顶点。
- 引用表按原 POI 顺序流式写出；电脑内存主要为 O(V + A) 的边界和空间索引，
  以及 O(U × 路径长度) 的去重表。设备只读取所选结果的引用与字符串。

最终还需要检查真实源数据覆盖范围、年代差异、缺失层级、争议重叠和结果
位置，并在设备上验证搜索、文字、滚动与地图跳转。来源记录不代替这些验证。
